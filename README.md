# yoxi 順路圈 RideTogether 互動原型

2026 和泰 AI 黑客松（yoxi 提案方向四）手機 App 互動原型。Vue 3 + Vite + Leaflet，乘客端 12 個畫面、司機端 4 個畫面。

兩個方案結合成一條故事線：**城市脈動**負責「不搭車也每天打開」（各區等車時間預測、個人移動預報、城市版圖），**順路圈**負責把預報轉成真實訂單（集合點共乘、透明分攤、企業補助）。

## 啟動

```bash
npm install
npm run dev        # http://localhost:5180
npm run build      # 輸出 dist/，可離線開啟
```

## 三個身分

| 身分 | 內容 |
|------|------|
| 乘客端 | 最終版：以 yoxi 現行介面為底，12 個畫面 |
| 司機端 | 共乘派單與收入，4 個畫面 |
| yoxi 現況 | 依實機錄影還原的現行流程，4 個畫面，做前後對照 |

## 操作

| 按鍵 | 功能 |
|------|------|
| 左右方向鍵 | 上一步／下一步 |
| D | 切換乘客端／司機端 |
| P | 錄影模式（隱藏左側面板，只留手機） |

## 設計與資料來源

- 品牌色取自 yoxi.app 官網：主紅 `#F14A42`、海軍藍 `#051122`、深藍 `#0C4C80`、灰藍 `#778AA4`
- 路線為 OSRM 依台北真實道路計算（`src/data/routes.json`）
- 底圖為 OpenStreetMap 道路／河流／公園向量資料（`public/basemap.json`），不需網路
- 車資分攤統一在 `src/data/scenario.js`，**目前採用里程占比**（Llona 分支的版本）：每人依自己實際共乘的里程占總里程的比例分攤，另加每人 $10 媒合服務費
  - 逐段分攤（提案書原本寫的：共同路段平均分攤、專屬路段自行負擔）保留為 `computeSplit()`，要換規則把 `pctSplit` 改回 `split.riders` 即可
  - 兩者差最多的是有專屬路段的林先生：里程占比 $120、逐段分攤 $131
- 費率以台北計程車跳表 × 1.25 計算（依資料：5–6.5 km 行程 89% 落在 $200–300）；碳排係數 0.173 kg/km 為估算值，正式提案需以 yoxi 資料重新校準

## 真實資料（analysis/）

- 來源：`~/Downloads/yoxi_數據資料.csv`（2026/02–04，96.5 萬筆），不放進專案
- `analysis/analyze.py` 產出 `src/data/real.json`：六角格等車中位數（四個時段）、地標周邊中位數與 90 百分位、示範走廊出發時間曲線、通勤比例
- `analysis/pool_sensitivity.py`：共乘媒合率 × 媒合條件 × 需求倍數
- 分析結論與「哪些數字仍是示意」見 `analysis/REPORT.md`
- 重跑：`uv run --with pandas --with numpy python analysis/analyze.py`

### 城市脈動地圖

- 約 450 m 六角格的中心以圓點呈現：**點越大＝該時段叫車越多**
- 兩種著色可切換：**需求熱度**（深藍色階，每天叫車筆數）、**等車時間**（紅色階，等車中位數）
- 每天少於 2 筆的格子視為非熱點，一律灰色小點，避免用少量樣本的顏色誤導

### yoxi 現況還原（src/screens/origin/）

依 2026/09/29 yoxi App 實機錄影逐格比對還原，供簡報做「現況 → 提案」對照：

- 首頁（地圖、上下車點、活動橫幅、紅色側選單）、設定下車地點、叫車、行程紀錄
- 叫車頁還原了「立即叫車／預約」切換：選預約後分頁會變成日期時間膠囊，車種清單也跟著變少（不限車種、減碳車種不可預約），且不再顯示「N 分鐘後抵達」
- 付款方式清單、點數折抵、以及「預約叫車只能以信用卡、電子支付或企業簽單支付車資」的提醒，文案皆取自錄影
- 車種名稱、價格、說明文字與配色（navy #0B1F36、側選單紅 #DE262A）均取自錄影畫面
- 錄影帳號未綁卡所以無法預約；原型的「新增付款方式」會補一張信用卡，讓流程走得完

### 乘客端（最終版）

以 yoxi 實機介面為底，只在它原本的動線上加東西，標 `新` 的是提案新增的部分。
沒有底部分頁列，每個內頁左上都有返回鈕。

| 畫面 | 沿用 yoxi 原本的 | 新增 |
|------|----------------|------|
| 首頁 | 地圖、活動橫幅、上下車點輸入、機場接送、側選單 | 地圖上的叫車熱點疊圖、移動預報跑馬燈、城市脈動列、順路圈邀請卡 |
| 叫車 | 車種清單、付款／點數／乘車需求、確認叫車 | 第三個分頁「順路共乘」；預約時間選單附各時段等車預估 |
| 媒合詳情 → 分攤試算 → 前往集合點 → 行程中 → 行程完成 | 底部面板與按鈕樣式 | 集合點取捨對照、里程占比分攤、共乘過程 |
| 城市脈動、移動預報 | — | 首頁的熱點列與跑馬燈點進來 |
| 我的順路圈、城市版圖、企業方案 | 側選單 | 收在側選單，標 `新` |

- 情境用分析過的民生社區 → 內湖科學園區走廊，車資與等車時間來自 `real.json`
- 版面語彙定義在 `src/style.css` 的 `.yx` 區塊（navy #0B1F36、red #D8303C、按鈕圓角 4px）

### 出發方案比較（我的移動預報）

- 車型：純電／舒適／尊榮／六人座。六人座車資較高但可分攤人數較多，共乘每人反而更省
- 四種方案並列：順路共乘、自己叫車、捷運 + 共乘接駁、捷運 + 步行
- 等車與車程來自行程資料；**車型費率、捷運時刻與接駁時間為示意值**（CSV 無車型欄位，也無大眾運輸資料），設定在 `src/data/travel.js`

## 示範情境

三位通勤者從民生社區附近步行 5 到 8 分鐘到民生敦化路口集合，共乘至內湖科學園區，依序於洲子街、瑞光路、港墘路下車。

| 乘客 | 分攤 | 自己叫車 | 省下 |
|------|------|---------|------|
| 你（瑞光路） | $109 | $250 | $141 |
| 陳小姐（洲子街） | $90 | $250 | $160 |
| 林先生（港墘路） | $131 | $265 | $134 |

車資依資料校準為跳表 1.25 倍。司機本單收入：$300 + 共乘效率獎金 $30 = $330。
